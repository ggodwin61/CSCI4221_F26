# 3D Water Tank With Flow Readings

This OpenSCAD model represents a transparent water tank with a visible water
level, a graduated level gauge, and separate inlet and outlet valves with flow
readings. Save the code as an `.scad` file and render it in OpenSCAD.

```openscad
$fn = 80;

tank_height = 100;
tank_radius = 42;
wall = 3;
water_level = 62;
pipe_radius = 5;

// Transparent cylindrical tank
color([0.55, 0.8, 1, 0.35])
difference() {
	cylinder(h=tank_height, r=tank_radius);
	translate([0, 0, wall])
		cylinder(h=tank_height, r=tank_radius-wall);
	translate([0, 0, tank_height-wall])
		cylinder(h=wall+1, r=tank_radius-wall);
}

// Base and top rim
color("gray") translate([0, 0, -4]) cylinder(h=4, r=tank_radius+5);
color("gray") translate([0, 0, tank_height]) cylinder(h=4, r=tank_radius+2);

// Water inside the tank
color([0.03, 0.25, 0.9, 0.75])
	translate([0, 0, wall])
		cylinder(h=water_level, r=tank_radius-wall-1);

// Inlet pipe on the left: flow enters the tank
color("silver")
	translate([-tank_radius-25, 0, tank_height-25])
		rotate([0, 90, 0]) cylinder(h=25, r=pipe_radius);
color("orange")
	translate([-tank_radius-12, 0, tank_height-25])
		rotate([0, 90, 0]) cylinder(h=10, r=9);
color("black")
	translate([-tank_radius-13, 0, tank_height-25])
		rotate([0, 90, 0]) cylinder(h=12, r=2);

// Outlet pipe on the right: flow leaves the tank
color("silver")
	translate([tank_radius, 0, 25])
		rotate([0, 90, 0]) cylinder(h=25, r=pipe_radius);
color("red")
	translate([tank_radius+12, 0, 25])
		rotate([0, 90, 0]) cylinder(h=10, r=9);
color("black")
	translate([tank_radius+11, 0, 25])
		rotate([0, 90, 0]) cylinder(h=12, r=2);

// Tank-level gauge on the front-right side
color("black")
	translate([tank_radius+1, -2, 5]) cube([2, 4, 90]);
for (z = [10:10:90]) {
	color("black")
		translate([tank_radius+1, -3, z]) cube([8, 6, 1]);
}
color("lime")
	translate([tank_radius+1, -4, water_level]) cube([11, 8, 2]);

// Flow-direction arrows
color("green")
	translate([-tank_radius-34, 0, tank_height-25])
		rotate([0, 90, 0]) cylinder(h=8, r=2);
color("blue")
	translate([tank_radius+25, 0, 25])
		rotate([0, 90, 0]) cylinder(h=8, r=2);
```

## Readings

- **Tank level:** 62% full, shown by the green marker on the vertical gauge.
- **Water in-flow valve:** orange handle on the left; the green indicator shows
  flow entering the tank.
- **Water out-flow valve:** red handle on the right; the blue indicator shows
  flow leaving the tank.

The valve handles are parallel to their pipes when open and can be rotated 90°
to represent closed valves.
