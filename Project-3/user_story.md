## Story

As a new professor, I want to search for my assigned classroom using its room number and building so that I can find the correct floor and room inside the building before my class begins.

## Sprint Scope

This story describes one specific use of Classroom Search: finding a recorded classroom from its room number and building, then viewing its building name, floor, and indoor location on an existing floor map where available. If no floor map is available, the result still displays the recorded building, floor, and room information and states that the map is unavailable. The story is intended for one sprint using existing classroom records and maps; creating floor maps, live indoor positioning, and turn-by-turn directions are outside its scope.
