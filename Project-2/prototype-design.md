# Settings Prototype — Campus Map Application

**Contributor:** Garret Godwin  
**Group:** 1  
**Sprint:** 2 — Project 2

## Purpose

The settings screen lets users customize how they navigate the campus map. It is a Figma prototype; the displayed controls do not establish that the app's features or backend are implemented.

[Open the Group 1 Figma design](https://www.figma.com/design/KLO3v6UELNYGNn7ymmxZA8/SE-F26-%7C-Group-1?node-id=33-33&t=BqqVxLNIdWxKKX7t-1). The settings design belongs on the separate **Settings** page.

## Intended users — proposed for team discussion

- Students locating classrooms and campus services.
- Faculty and staff locating buildings and facilities.
- Visitors unfamiliar with campus.
- Users who need step-free routes or more readable map labels.

Confirm these users and the supported campuses against Project 1. The initial design's default-campus label is a placeholder that should be checked against the group's actual campus.

## Screen and controls

| Area | Prototype options | Intended behavior |
| --- | --- | --- |
| Map and navigation | Default campus, map appearance, use my location | Choose the map context and appearance; request device location permission when needed |
| Accessibility | Step-free routes, larger map labels | Indicate routing and label preferences for the future app |
| Notifications | Campus alerts, route updates | Indicate notification preferences for the future app |
| Help and about | Help and feedback, privacy and permissions | Open supporting information screens |
| Navigation | Back to map | Return to the main map screen |

The layout follows the existing yellow header and blue accents and uses a phone-sized screen with reusable settings rows and switches.

## Proposed click-through flow

1. Open the main campus map screen.
2. Select Settings from the main screen's navigation.
3. View or change a preference.
4. Select Back to map to return to the map.

This is the intended flow. Verify the Figma prototype connections and any needed destination screens before marking the task complete.
